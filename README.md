# FuturesSoon

台指期（臺灣加權股價指數期貨）每日資料網站：看 K 線圖，也看三大法人（自營商、投信、外資）的期貨買賣超。

> 狀態：規劃完成，開發中。

## 功能

- 每日 K 線圖（開高低收、成交量、未平倉）
- 三大法人期貨買賣口數與未平倉變化
- 商品：臺股期貨（大台 TX）、小型臺指期貨（小台 MTX）、微型臺指期貨（微台 TMF）
- 保留約一年的每日資料
- 之後預計擴充其他指數（例如美股大盤、台灣加權指數）

## 運作方式

```
期交所 ──(每天 2 次)──> GitHub Actions ──寫入──> Supabase 資料庫
                                                        │
瀏覽器 <────────────── Vercel（網站）<──── 讀取 ─────────┘
```

- **資料來源**：臺灣期貨交易所。歷史資料用官網 CSV 回補，每日更新用 OpenAPI。
- **每日抓取**：GitHub Actions 在台灣時間 17:00 和 19:00 各執行一次，重複抓取不會重複存。
- **資料庫**：Supabase（PostgreSQL）。
- **網站**：Vercel。
